cd electric-
./run.sh                      # يُنشئ البيئة ويثبّت ويشغّل

أو يدويًا:

```bash

pip install -r requirements.txt
uvicorn mirsad.main:app --host 0.0.0.0 --port 8000
```

ومن سطر الأوامر مباشرة:

```bash
python -m mirsad.cli صورة.jpg --html تقرير.html --json تقرير.json
python -m mirsad.cli --compare نسخة_أ.jpg نسخة_ب.jpg
```

## 🧠 ماذا تفعل المنظومة بالضبط؟

### 1) هوية الدليل وسلامته
| القدرة | التفاصيل |
|---|---|
| تعريف النوع من التوقيع الثنائي | أكثر من 60 توقيعًا (صور، فيديو، صوت، أرشيف، تنفيذي، قواعد بيانات، صور أقراص جنائية E01/VMDK، التقاطات شبكة) |
| كشف تمويه الامتداد | مقارنة الامتداد المعلن بالمحتوى الحقيقي — كشف «ملف .txt هو في الحقيقة PNG» |
| البصمات التشفيرية | MD5 · SHA-1 · SHA-256 · SHA-512 · SHA3-256 · BLAKE2b · CRC32 |
| تجزئة سياقية CTPH | تنفيذ كامل لخوارزمية spamsum/ssdeep لقياس **نسبة تشابه** بين دليلين معدَّلين جزئيًا |
| تجزئة القطاعات | SHA-256 لكل 4 ك.بايت — يحدد **أي جزء بالضبط** تغيّر بين نسختين |

### 2) استخراج البيانات الوصفية (محلّلات مكتوبة من الصفر)
- **EXIF/TIFF كامل**: IFD0 · Exif IFD · GPS IFD · Interop IFD · IFD1 (المصغّرة) · كشف MakerNote — مع أكثر من 180 وسمًا مترجَمًا وتفسيرًا بشريًا (سرعة الغالق، الفتحة، الفلاش…).
- **GPS**: فك الإحداثيات الستينية إلى عشرية + الارتفاع + التوقيت الذري + روابط خرائط جاهزة.
- **JPEG**: تشريح كل المقاطع (SOI/APPn/DQT/DHT/SOF/SOS/EOI)، جداول التكميم، تقدير الجودة بمقياس IJG، XMP، IPTC، ICC، Photoshop IRB، Adobe APP14، MPF.
- **PNG**: كل الكتل مع **تحقق CRC لكل كتلة** (فشل CRC = تعديل مباشر على البايتات)، tEXt/zTXt/iTXt، eXIf، iCCP، tIME.
- **ISO-BMFF** (MP4/MOV/HEIC/AVIF): شجرة الصناديق كاملة، أوقات mvhd/tkhd، وسوم Apple/iTunes، زاوية الدوران من مصفوفة التحويل، صناديق `free` التي تحوي بقايا.
- **RIFF/WebP/WAV/AVI** · **GIF** (إطارات وتعليقات) · **Matroska**.
- **PDF**: قاموس Info، XMP، عدد **التحديثات التزايدية** (النسخ القديمة ما زالت داخل الملف!)، معرّفا المستند، الخطوط، الملفات المدمجة، ومؤشرات الخطر (`/JavaScript` `/OpenAction` `/Launch` `/EmbeddedFile`…).
- **OOXML** (docx/xlsx/pptx): اسم المُنشئ وآخر مُعدِّل، زمن التحرير الكلي، **التعديلات المتتبّعة وأسماء المحرّرين**، الماكرو، الروابط الخارجية، وطوابع ZIP الزمنية.
- **الصوت**: وسوم ID3/FLAC/MP4 وخصائص التيار.

### 3) 🔥 استرجاع الميتاداتا «الممسوحة» — قلب المنظومة
عندما تُمسح البيانات الوصفية، تبقى آثار فيزيائية داخل الملف. المنظومة تمسح **كل بايت** بحثًا عن:
1. **شظايا EXIF/TIFF** في أي موضع (داخل التيار، في `free`، في الذيل) — لا المقطع القياسي فقط.
2. **حزم XMP** كاملة أو جزئية (`<?xpacket`, `x:xmpmeta`, `rdf:RDF`) مع فك سجل التعديلات.
3. **الصور المصغّرة والمعاينات المدمجة** — تُستخرج كملفات حقيقية، وقد تُظهر **المشهد قبل القص أو التعديل**.
4. ملفات تعريف **ICC** وكتل **Photoshop IRB/IPTC** التي تكشف الجهاز والبرنامج.
5. **بصمة المصدر بلا ميتاداتا إطلاقًا**: جداول التكميم + ترتيب المقاطع + التقليل اللوني → تحديد ما إذا كانت الصورة خرجت من كاميرا، أو مرّت بفوتوشوب، أو أُعيد ترميزها عبر تطبيق مراسلة.
6. البيانات الملحقة بعد نهاية الملف المنطقية، والمساحات غير المُفسَّرة (slack).

### 4) تحليل الصور الجنائي
| المحرك | الأساس العلمي |
|---|---|
| **فكّ معاملات JPEG الحقيقية** | فاكّ ترميز هوفمان كامل (ITU-T T.81) يستخرج معاملات DCT **المُكمَّمة كما خزّنها المُرمِّز** — لا تقديرًا من البكسلات |
| **كشف الضغط المزدوج** | دورية مدرّج المعاملات بالارتباط الذاتي (Popescu & Farid 2004) |
| **قانون بنفورد المعمّم** | ملاءمة نموذج `N·log10(1+1/(s+d^q))` لمعاملات DCT (Fu, Shi & Su 2007) |
| **ELA** | Error Level Analysis مع تحديد المناطق الشاذة بـ z-score قوي (MAD) |
| **أشباح JPEG** | JPEG Ghosts (Farid 2009) — تقدير جودة آخر حفظ وكشف المناطق مختلفة التاريخ |
| **نسخ ولصق داخلي** | كتل 16×16 مرتبة معجميًا على DCT منخفض التردد + تصويت متجه الإزاحة + **تحقق بكسلي** + **فلتر الكثافة المكانية** لمنع الإنذارات الكاذبة (Fridrich 2003) |
| **تحليل الضجيج** | بقايا عالية التمرير + خريطة انحراف مناطقية لكشف اللصق والتنعيم الموضعي |
| **مطابقة المصغّرة** | مقارنة الصورة بالمصغّرة المدمجة: اختلافها = تعديل بعد الالتقاط، واختلاف النسبة = قصّ |
| **المدرج التكراري** | كشف «نمط المشط» الدال على تعديل المستويات/التباين |

### 5) كشف إخفاء المعلومات (Steganography)
- استخراج **مستويات البت الأدنى** لكل قناة كصور قابلة للمعاينة (النص الظاهر فيها = دليل مباشر).
- **اختبار كاي-تربيع** (Westfeld & Pfitzmann 1999) مع **ضابط الأزواج المُزاحة** الذي أضفناه لإلغاء الإنذارات الكاذبة في الصور الناعمة.
- **تحليل RS** الكامل بالمعادلة التربيعية المعيارية (Fridrich 2001) لتقدير **نسبة الحمولة المخفية** لكل قناة.
- إنتروبيا شانون + كاي-تربيع + مونت-كارلو π + الارتباط التسلسلي + خريطة إنتروبيا تكشف الكتل المشفّرة المدسوسة.

### 6) النحت والاستخراج
بحث بايتي عن توقيعات 17 نوع ملف داخل الدليل، مع **تحديد النهاية الحقيقية** لكل نوع (نهاية PNG بـ IEND، نهاية ZIP بـ EOCD، فكّ GZIP…) ثم **استخراج الملف فعليًا** وتسليمه للتحميل مع بصمته.

### 7) المؤشرات والنصوص
استخراج سلاسل ASCII/UTF-16/عربية مع إزاحاتها، ثم استخلاص: بريد · روابط · IPv4/IPv6 · MAC · هواتف · مسارات ويندوز/يونكس · GUID · محافظ بتكوين وإيثريوم · **بطاقات ائتمان متحقَّق منها بـ Luhn** · مفاتيح AWS · JWT · نطاقات onion · إحداثيات.

### 8) الخط الزمني وكشف التضارب
تجميع كل الطوابع الزمنية (EXIF · XMP · PNG tIME · mvhd/tkhd · PDF · ZIP · ترويسة PE) في خط واحد، مع كشف: تواريخ مستقبلية، تسلسل مقلوب (تعديل أقدم من الالتقاط)، وفجوات التحرير.

### 9) إدارة القضايا وسلسلة الحيازة
- قاعدة SQLite للقضايا والأدلة، مع حفظ **نسخة أصلية** من كل دليل.
- **سجل حيازة مُسلسل تشفيريًا**: كل قيد يحمل بصمة القيد السابق، فأي تعديل أو حذف لاحق **يكسر السلسلة ويُكتشف** (`/api/cases/{id}/chain`).
- التحقق من السلامة بإعادة حساب SHA-256 للنسخة المخزّنة.
- تصدير **حزمة أدلة ZIP** تحوي: التقرير JSON + تقرير HTML + ملخص نصي + كل المخرجات البصرية + النسخة الأصلية + سلسلة الحيازة.

## 🔌 الواجهة البرمجية (REST)

وثائق تفاعلية كاملة على `/docs`.

| المسار | الوظيفة |
|---|---|
| `POST /api/analyze` | رفع دليل وتحليله بالكامل (يرجع التقرير JSON) |
| `POST /api/compare` | مقارنة دليلين: تطابق + نسبة تشابه سياقية + أول موضع اختلاف + الكتل المتغيّرة |
| `GET  /api/evidence/{id}/report.html` | تقرير جنائي جاهز للطباعة/PDF |
| `GET  /api/evidence/{id}/package` | حزمة أدلة ZIP كاملة |
| `GET  /api/evidence/{id}/hex?offset&length` | عارض هيكس |
| `GET  /api/evidence/{id}/verify` | التحقق من سلامة النسخة المخزّنة |
| `POST /api/cases` · `GET /api/cases/{id}/chain` | إدارة القضايا والتحقق من سلسلة الحيازة |

## ⚠️ حدود معروفة (شفافية علمية)

- **الضغط المزدوج**: إذا كان التكميم الثاني أخشن من الأول (حفظ بجودة أقل) تُمحى آثاره فيزيائيًا — غياب المؤشر لا ينفي إعادة الحفظ.
- **ELA** مؤشر مساعد فقط؛ الحواف والنصوص تعطي خطأً مرتفعًا طبيعيًا.
- **كاي-تربيع للإخفاء** يفقد حساسيته في الصور ذات المدرّج الناعم — ولهذا يُشغَّل تحليل RS بالتوازي.
- فكّ معاملات JPEG يدعم الوضع **الأساسي (Baseline)**؛ الصور التقدمية (Progressive) تُحلَّل ببقية المحركات.
- الأداة تحلل **الملفات**؛ لا تشمل حاليًا تصوير الأقراص الحية أو استخراج بيانات الهواتف.

│   ├── strings_.py      السلاسل ومؤشرات IOC
│   ├── exif.py          محلّل TIFF/EXIF كامل من الصفر
│   ├── jpeg.py          تشريح مقاطع JPEG · ICC · IPTC · جداول التكميم
│   ├── jpegdct.py       فاكّ ترميز هوفمان ومعاملات DCT + بنفورد
│   ├── containers.py    PNG · GIF · RIFF · ISO-BMFF · Matroska
│   ├── documents.py     PDF · OOXML · ZIP
│   ├── recovery.py      محرّك استرجاع الميتاداتا الممسوحة
│   ├── imaging.py       ELA · أشباح · ضجيج · نسخ-لصق · RS/كاي-تربيع
│   ├── carver.py        نحت الملفات المدمجة
│   ├── timeline.py      الخط الزمني وكشف التضارب
│   ├── case.py          القضايا وسلسلة الحيازة المُسلسلة تشفيريًا
│   ├── report.py        توليد التقارير HTML/نصي
│   └── analyzer.py      المنسّق ومؤشر الشبهة
