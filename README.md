# ⚡ إلكترو بلوك — برمّج الـ ESP32 بالبلوكات من موبايلك

موقع ويب بيسمح لك تبرمج شريحة **ESP32** عن طريق **سحب وإفلات البلوكات** (زي سكراتش) — من الموبايل مباشرة، **من غير لاب توب خالص**.

## 🎯 الفكرة

1. 🧩 اسحب بلوكات ورتّبها (ليد، زر، سيرفو، حساسات، شروط، تكرار…)
2. 💻 الموقع بيحوّلها **أوتماتيك** لكود [MicroPython](https://micropython.org) وتشوفه لحظة بلحظة
3. 📱 وصّل الشريحة بالموبايل بكابل **OTG** واضغط «اشحن على الشريحة»
4. 🚀 البرنامج ينزل على الشريحة ويشتغل **بشكل حقيقي** — حتى لو فصلت الموبايل، الشريحة تكمل شغالة!

## ✨ المميزات

| الميزة | التفاصيل |

| 🕹️ محاكي مدمج | جرّب برنامجك قبل الرفع: ليد، زر، سيرفو، بازر، حساس مسافة، مقاومة متغيرة |
| 🐍 كود حقيقي | شوف كود MicroPython المولّد، انسخه أو نزّله كـ `main.py` |
| 📱 رفع مباشر من المتصفح | عبر Web Serial API — أول مرة بيثبّت MicroPython (مرة واحدة)، وبعدها أي تعديل بينزل في ثواني |
| 🔌 تشغيل مستقل | البرنامج بيتسجل في `main.py` وبيشتغل لوحده مع كل تشغيل للشريحة |
| 📚 أمثلة جاهزة | 7 أمثلة تعليمية: وميض، زر، إشارة مرور، سيرفو، نغمات، إنذار مسافة، تحكم بالإضاءة |
| 💾 مشاريع | حفظ تلقائي في المتصفح + تصدير/استيراد مشاريع كملفات |

## 📱 المتطلبات

- **أندرويد** (أو كمبيوتر) مع **Chrome أو Edge** — للأسف الآيفون وسفاري وفايرفوكس مش بيدعموا الـ Web Serial API
- كابل **OTG** لو من الموبايل (⚠️ لازم كابل بـ «داتا» مش كابل شحن بس)
- شريحة: **ESP32 الكلاسيكي** (الأشهر) أو **ESP32-C3** أو **ESP32-S3**

## 🚀 التشغيل (للمطوّرين)

الموقع **ثابت بالكامل** (static) — مفيش سيرفر ولا build:

```bash
# أي سيرفر ملفات بسيط
python3 -m http.server 8000
# أو
npx serve .
```

> ملاحظة: الـ Web Serial API محتاج HTTPS أو localhost — استخدم GitHub Pages أو استضافة بـ HTTPS.

## 🏗️ البنية التقنية

```
index.html            الصفحة الرئيسية (عربي RTL)
css/style.css         الثيم الداكن الكهربائي
js/
  blocks.js           تعريفات البلوكات المخصصة + قائمة الأدوات
  compiler.js         البلوكات → شجرة برنامج (AST)
  pygen.js            AST → كود MicroPython مع دوال مساعدة معلّقة بالعربي
  interpreter.js      مفسّر الـ AST للمحاكي (async مع إيقاف آمن)
  simulator.js        لوحة ESP32 افتراضية + مكونات
  simui.js            واجهة مكونات المحاكي
  repl.js             عميل MicroPython REPL عبر Web Serial (بروتوكول raw REPL الرسمي)
  flasher.js          تثبيت firmware عبر esptool-js
  app.js              الواجهة الرئيسية
libs/                 Blockly و esptool-js (self-hosted)
firmware/             ملفات MicroPython الرسمية للأنواع الثلاثة
```

**إزاي بيشتغل الرفع؟**
1. الموقع يفتح المنفذ التسلسلي (Web Serial) ويفحص: فيه MicroPython؟
2. لو مش موجود → يثبّت firmware MicroPython الرسمي عبر [esptool-js](https://github.com/espressif/esptool-js) (مرة واحدة)
3. بيكتب برنامجك في `main.py` عبر بروتوكول raw REPL (زي Thonny وmpremote بالظبط)
4. بيعمل reset — الشريحة تشتغل بالبرنامج الجديد وتطبع في الشاشة التسلسلية اللي في الموقع
